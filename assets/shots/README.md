# assets/shots — 기능 구간에 들어가는 «실제 앱 화면»

goditor.html 의 기능 구간 4개가 이 파일들을 그대로 참조한다.
파일이 없으면 깨진 이미지 대신 «준비 중» 회색 판이 뜬다(`img onerror` → `.shot-pending`).
파일을 여기 넣기만 하면 손 안 대고 살아난다 — HTML/CSS 를 고칠 필요 없다.

| 파일 | 구간 | 담아야 할 화면 |
|---|---|---|
| `editor-canvas.png` | ① 블록으로 쌓습니다 | 편집기 캔버스 — 상세페이지가 만들어져 있는 상태 |
| `blocks.png`        | ② 끌어다 놓습니다   | 블록(섹션) 쌓기 — 좌측 패널 + 블록 목록 |
| `preview.png`       | ③ 바로 미리봅니다   | 실시간 미리보기 — 모바일 폭 |
| `export.png`        | ④ 만든 걸 내보냅니다 | 내보내기 결과 |

## 규칙

- **지어낸 목업 금지.** 진짜 앱을 띄워 찍은 화면만 넣는다.
- 가로 폭은 화면에서 최대 472px(1280px 뷰포트 기준)로 줄어든다.
  레티나까지 감안해도 **가로 1600px 이면 충분하다** — 그보다 크면 그냥 무거워지기만 한다.
  (현재 `blocks.png` 는 3200×2000 · 676KB 라 2배 과하다. 줄일 여지가 있다.)
- 세로 비율은 자유다(`height:auto`). 다만 넷의 비율이 제각각이면 좌우 교차 리듬이 흔들리니
  가급적 16:10 근처로 맞춘다.
