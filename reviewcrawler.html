Review Crawler

네이버·쿠팡 상품 리뷰를, 별점·본문·사진까지 한 번에 표로 모읍니다.

다운로드 사용법 보기

macOS · Windows · GitHub에서 내려받기

스크롤하며 복붙하던 리뷰를, 표 한 장으로

상품 리뷰를 한 줄씩 긁어 옮기는 대신, 별점·본문·사진까지 자동으로 모읍니다.

네이버 스마트스토어·브랜드스토어와 쿠팡의 상품 리뷰를 같은 방식으로 수집합니다. 크롬 창을 실제로 열어 사람이 보는 화면 그대로 모으고, 결과는 엑셀(.xlsx)과 JSON으로 내 컴퓨터에 저장합니다 — 리뷰 사진까지 엑셀 셀 안에.

URL을 붙여넣으면 바로, 검색어를 넣으면 상품을 골라 수집합니다. 수집할 페이지 수도 고를 수 있고, 요청이 몰리면 스스로 속도를 늦춰 무리하지 않습니다.

설치형 데스크톱 앱이라 수집한 리뷰는 내 컴퓨터에 파일로 저장됩니다(당사 서버로 보내지 않음). 네이버는 처음 한 번 본인 계정으로 로그인해 두면 이후 자동으로 이어집니다.

네이버·쿠팡 상품 리뷰를 별점·본문·작성일·사진까지 모아 엑셀과 JSON으로 저장합니다. 네이버는 상품문의(Q&A)도 함께 수집합니다.

네이버·쿠팡을 한 도구로

네이버 스마트스토어·브랜드스토어와 쿠팡 상품평을 같은 방식으로 수집합니다. 네이버는 상품문의(Q&A) — 질문·답변까지 함께 담을 수 있습니다.

별점·본문·작성일·사진까지

리뷰의 별점, 작성자 표시명, 작성일, 본문, 리뷰 유형(일반·한달사용기·재구매), 첨부 사진을 함께 모읍니다.

엑셀과 JSON으로, 내 PC에

결과를 엑셀(.xlsx)과 JSON으로 동시에 저장합니다. 엑셀에는 리뷰 사진이 셀 안에 이미지로 들어갑니다. 모든 파일은 내 컴퓨터의 저장 폴더에 남습니다.

URL을 붙여넣거나, 검색해서

상품 URL을 붙여넣으면 바로, 검색어를 넣으면 검색 결과에서 상품을 골라 수집합니다. 수집할 페이지 수(5·15·50·최대)도 고를 수 있습니다.

실제 브라우저로, 무리 없이

크롬 창을 실제로 열어 사람이 보는 화면 그대로 수집하고, 요청이 몰리면 스스로 잠시 기다렸다가 이어받아 대상 사이트에 무리를 주지 않습니다.

사용 방법

붙여넣고, 모으고, 엑셀로.

  1. 네이버·쿠팡 상품 URL을 붙여넣거나, 검색어로 상품을 찾습니다.
  2. 수집할 페이지 수를 고르고 시작하면, 크롬 창에서 리뷰를 순서대로 모읍니다.
  3. 끝나면 엑셀(.xlsx)·JSON 파일이 저장 폴더에 만들어집니다 — 사진까지.

네이버는 처음 한 번 본인 계정으로 로그인해 두면 이후 자동으로 이어집니다. 수집한 데이터는 대상 플랫폼의 이용약관과 관련 법령을 지켜 사용해 주세요.

개인정보처리방침 전문

1. 수집·이용하는 정보 (이용자)

  • 이용 등록(기기 인증)을 위한 접속 IP 주소: 라이선스 확인에 사용되며 당사 서버에 저장됩니다.
  • (선택) 진단 로그: 사용자가 「진단 로그 전송」을 켠 경우에만, 앱 버전·실행 환경·입력한 상품 주소·수집 건수 등이 오류 개선 목적으로 전송됩니다. 리뷰 본문·작성자 정보·이미지는 포함되지 않습니다.

2. 수집한 리뷰 데이터의 처리

  • 대상 상품 페이지에서 수집한 리뷰(별점·작성자 표시명·본문·사진 등)는 전적으로 사용자 PC에 파일로 저장되며, 당사 서버로 전송하지 않습니다.
  • 수집 데이터에는 리뷰 작성자의 공개 표시명 등 제3자의 정보가 포함될 수 있으므로, 대상 플랫폼의 이용약관과 관련 법령을 준수하여 이용해야 합니다.

3. 보유 및 파기

  • 수집 결과 파일의 보관·삭제는 사용자가 직접 관리합니다.
  • 라이선스 확인용 IP 등 계정 정보의 보유·파기는 소문의섬 서비스 정책을 따릅니다.

4. 제3자 제공

  • 당사가 보관하는 이용자 정보를 제3자에게 판매·제공하지 않습니다.
