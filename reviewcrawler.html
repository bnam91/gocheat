REVIEW CRAWLER

네이버·쿠팡 상품 리뷰 — 평점·본문·사진 — 를 한 번에 표 하나로 모읍니다.

다운로드

macOS · Windows

스크롤해서 복사-붙여넣기 하던 리뷰를, 표 하나로

한 줄씩 긁어 옮기는 대신, 평점·본문·사진을 자동으로 수집합니다.

네이버 스마트스토어·브랜드스토어와 쿠팡의 상품 리뷰를 같은 방식으로 수집합니다. 실제 크롬 창을 열어 사람이 화면에서 보는 그대로를 수집하고, 결과를 엑셀(.xlsx)과 JSON으로 내 컴퓨터에 저장합니다 — 리뷰 사진은 엑셀 셀 안에 바로 들어갑니다.

URL을 붙여넣으면 바로 작업이 시작되고, 검색어를 입력하면 수집할 상품을 고를 수 있습니다. 수집할 페이지 수도 고를 수 있고, 요청이 몰리면 스스로 속도를 늦춰 무리를 주지 않습니다.

설치형 데스크톱 앱이라 수집한 리뷰는 내 컴퓨터에 파일로 저장됩니다(서버로 전송하지 않음). 네이버는 처음 한 번 본인 계정으로 로그인하면 이후엔 자동으로 이어집니다.

네이버·쿠팡 상품 리뷰 — 평점·본문·작성일·사진 — 을 모아 엑셀과 JSON으로 저장합니다. 네이버는 상품 Q&A도 함께 수집합니다.

네이버·쿠팡을 한 도구로

네이버 스마트스토어·브랜드스토어와 쿠팡의 상품 리뷰를 같은 방식으로 수집합니다. 네이버는 상품 Q&A — 질문과 답변 — 도 함께 담을 수 있습니다.

평점·본문·작성일·사진까지

리뷰의 별점, 작성자 표시 이름, 작성일, 본문, 리뷰 유형(일반/한달사용/재구매), 첨부 사진을 모읍니다.

엑셀·JSON으로, 내 PC에

결과를 엑셀(.xlsx)과 JSON으로 동시에 저장합니다. 엑셀 파일에서는 리뷰 사진이 셀 안에 이미지로 삽입됩니다. 모든 파일은 내 컴퓨터의 저장 폴더에 남습니다.

URL 붙여넣기, 또는 검색

상품 URL을 붙여넣으면 바로 작업이 시작되고, 검색어를 입력하면 검색 결과에서 수집할 상품을 고를 수 있습니다. 수집할 페이지 수(5 / 15 / 50 / 최대)도 고를 수 있습니다.

실제 브라우저로, 무리 없이

실제 크롬 창을 열어 사람이 화면에서 보는 그대로를 수집하고, 요청이 몰리면 스스로 잠깐 멈췄다가 다시 이어갑니다 — 대상 사이트에 무리를 주지 않습니다.

이용방법

붙여넣고, 수집하면, 엑셀로.

  1. 네이버 또는 쿠팡 상품 URL을 붙여넣거나, 검색어로 상품을 찾습니다.
  2. 수집할 페이지 수를 정하고 시작하면 — 크롬 창에서 순서대로 리뷰를 모읍니다.
  3. 완료되면 저장 폴더에 엑셀(.xlsx)과 JSON 파일이 생성됩니다 — 사진 포함.

네이버는 처음 한 번 본인 계정으로 로그인하면 이후엔 자동으로 이어집니다. 수집한 데이터는 대상 플랫폼의 이용약관과 관련 법규를 준수해 사용해 주세요.
