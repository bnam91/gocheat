화면을 찍는 게 아니라 원본을 그대로 가져옵니다

스크린샷이 아니라, 상세페이지에 업로드된 원본 이미지 파일 그대로입니다.

GODIV는 상세페이지를 화면 이미지로 캡처하지 않습니다. 페이지에 실제로 있는 원본 이미지 파일을 그대로 내려받습니다. 그래서 화질이 깨지지 않고, 처음 업로드됐을 때의 선명함 그대로 유지됩니다.

GoFullPage 같은 화면 캡처 도구는 화면에 보이는 것을 찍기 때문에 글자나 세밀한 부분이 뭉개집니다 — 하지만 GODIV는 원본을 그대로 가져오기 때문에, 내 상품 페이지에 그대로 재사용할 수 있는 화질을 얻습니다.

상품을 등록하는 쇼핑몰 운영자와 상세페이지를 작업하는 디자이너를 위해 만들었습니다. 앞으로 상세페이지 편집 도구 goditor(GODITOR)와 연동될 예정입니다.

지금 브라우저에 열려 있는 상세페이지의 본문 이미지를 위에서 아래 순서 그대로 다운로드 폴더에 저장합니다. 네이버 스마트스토어·브랜드스토어, 쿠팡, 와디즈를 지원합니다.

끝까지 빠짐없이 가져옵니다

접혀 있는 상세페이지 섹션을 자동으로 펼치고, 늦게 불러와지는 이미지까지 기다렸다가 수집합니다. 찾은 개수와 저장한 개수를 항상 보여줍니다(예: "완료: 33/33장"). 일부가 실패해도 다 된 것처럼 넘어가지 않고 이유를 정확히 보여줍니다.

순서대로, 폴더별로 깔끔하게

상세페이지에 나오는 순서대로 01, 02, 03…으로 번호를 매겨 Downloads › godiv › 상품명 폴더에 저장합니다.

브라우저 안에서만 동작합니다

이미 열어둔 페이지만 읽습니다. 별도 서버로 페이지를 다시 긁어오지 않고, 어느 페이지에서 무엇을 받았는지 서버로 보내지도 않습니다.

이용방법

클릭 세 번이면 끝입니다.

  1. 지원하는 사이트에서 상세페이지를 엽니다.
  2. 오른쪽 위 GODIV 패널에서 GODITOR 계정으로 로그인합니다.
  3. "이 페이지 이미지 다운로드"를 클릭 — 끝입니다.

goditor(GODITOR) 계정으로 로그인해서 사용합니다. 계정이 없다면 먼저 가입하세요.
