GODITOR

못으로 칼국수 자르지 마세요.

피그마는 와이어프레임 도구지, 상세페이지 도구가 아닙니다. 매번 어색했죠. 그래서 상세페이지 전용으로 다시 만들었습니다. 블록 쌓고, 텍스트 넣고, 미리보기. 그게 전부입니다.

이벤트 기간 무료 다운로드 → · 로그인 / 가입 →

지금은 이벤트 기간이라 가입 즉시 전체 기능을 쓸 수 있어요. 로그인하면 다운로드 링크가 나옵니다.
이벤트 종료 후 요금은 요금제에서 안내드려요.

주요 기능

  • · 블록 단위로 섹션을 쌓아 올리는, 머리 안 굴려도 되는 에디터
  • · 이미지·텍스트·CTA 블록 드래그 앤 드롭
  • · 작업한 그대로 실시간 미리보기
  • · 한 번 만들고 다시 안 만들기

GODITOR 요금제

Event 이벤트 기간 — 지금은 전 등급을 무료로 드립니다

등급은 네 가지, 지금은 전부 무료입니다.

GODITOR 는 구독제입니다. 아래 네 등급이 실제 제품 구성이고, 이벤트 기간에는 가입만 하면 어느 등급이든 제한 없이 쓰실 수 있어요.

예시 등급별 기능 구분은 예시입니다. 실제 적용 내용과 다를 수 있어요. 구독 주기와 금액은 이벤트 종료 전에 안내드립니다.
