## 1. 유저 렌즈 — 「누구의 눈으로 보는가」

★**상태가 아니라 사람으로 나눈다.** 정본은 `ops/qa/lenses.json`.

| 렌즈 | 누구 | 이 사람만 겪는 것 |
|---|---|---|
| 처음 온 사람 | 비로그인 | 여기가 «뭐 하는 곳인지» 알 수 있나 |
| 가입만 한 사람 | 앱 0개 | 빈 상태가 «덜 만든 것»으로 보이나 |
| 앱 하나 쓰는 사람 | 가장 흔함 | 카드 한 장의 정렬 |
| 앱 여럿 | 카드 2장+ | 간격·정렬이 무너지나 |
| 주문한 사람 | 주문 1건+ | 표·경고문이 뜨나 |
| 기한 임박 | 15일 남음 | «곧 끝난다»가 보이나 |
| 운영자 | tier 99 | 구매로 못 가는 등급이 티가 나나 |
| 세션 끊긴 사람 | 낡은 토큰 | 오류가 «사람 말»인가 |
| **JS 안 도는 사람** | 스크립트 차단 | ★`opacity:0` 로 시작하는 요소가 **영영 안 보이면 백지** |
| 느린 네트워크 | 3G 급 | 첫 화면이 «비어 보이나» |

⚠️**아직 렌즈에 없는 것**(다음에 넣을 것): 두 탭 동시 · 뒤로가기 · 딥링크 직접 접근 ·
폼 더블클릭 제출 · 아주 긴 이름/이모지 입력 · 화면 낭독기(스크린리더).

## 2. 렌즈별 검사

러너가 자동으로 본다: **안 보이는 요소 · 화면 밖 · 가려진 글 · 죽은 링크 · 낮은 대비 ·
가로 스크롤 · 본문 없음 · 콘솔 오류.**

손으로 봐야 하는 것:
- 처음 온 사람 → 히어로만 보고 «무엇을 파는 곳»인지 말할 수 있나
- 가입만 한 사람 → 빈 카드에 «다음에 뭘 하면 되는지»가 있나
- 세션 끊긴 사람 → 「다시 로그인해 주세요」 + 갈 곳

## 3. 전 페이지 공통 (18장 × 2폭 × 2테마 = 72조합)

```
node ops/qa/run.mjs                # 전 렌즈
node ops/qa/run.mjs guest nojs     # 특정 렌즈만
```

★크롬을 **먼저** 띄운다(현빈 실사용 PC라 **화면 밖 · headless**):
```
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new \
  --remote-debugging-port=9407 --user-data-dir=/tmp/qa-profile \
  --window-position=-2400,0 --no-first-run --no-default-browser-check about:blank &
```
⛔쓰고 나면 **반드시** 죽인다: `pkill -f 'remote-debugging-port=9407'; rm -rf /tmp/qa-profile`
⛔**OS 전체 화면 캡처 금지** — 남의 작업 화면이 찍힌다. CDP 스크린샷만.

## 4. ★★검사기 함정 — 거짓 경보 목록

**여기가 이 문서의 본체다.** 아래는 전부 2026-09-03 에 실제로 겪은 것이다.

| # | 증상 | 진짜 원인 | 어떻게 막나 |
|---|---|---|---|
| 1 | 「요소가 안 보인다」 | **애니메이션이 안 끝났다** | `getAnimations()` 대기 + **최소 대기 1.8초**(지연 시작 때문) |
| 2 | 「폭이 0이다」 | **`display:contents`** 는 자기 박스가 없다 | probe 가 `contents` 를 제외 |
| 3 | 「숨은 폼이 폭 0」 | 내가 **`[hidden]` 을 강제로 풀었다** | 가시성 검사는 **자연 상태**로 |
| 4 | 「고쳤는데 안 바뀐다」 | **캐시버스터를 안 올렸다** | 러너가 `setCacheDisabled` · 배포는 §7 |
| 5 | 「API 가 성공했다」 | **200 OK ≠ 제대로 됨**(download 는 인증 실패해도 ok:true) | 판정을 **「기록이 갱신되는가」**로 |
| 6 | 「문구가 없다」 | **내 정규식이 실제 문구를 안 담았다**(「맞지 않」·「달라요」·「바꿨어요」) | 먼저 **원시 문자열을 찍어 보고** 정규식을 짠다 |
| 7 | 「MX 차단이 안 된다」 | **일부러 통과**시킨다(`.test` — 우리 QA 계정) | `mx.js:26` 주석 확인 |
| 8 | 「동의가 일부만 체크」 | **기본이 켜져 있는데 내가 클릭해서 껐다** | 토글은 **현재 상태를 읽고** 조작 |
| 9 | 「레이트 리밋 없음」 | 응답이 JSON 이 아니었다(**Cloudflare 1015**) | 파싱 실패를 **통과로 세지 마라** |
| 10 | 「문법 OK」 | `node --check` 는 **구문만** 본다(`.mjs` 의 `require` 는 런타임 오류) | 설치 뒤 **실제로 한 번 실행** |
| 11 | 「테마가 안 바뀐다」 | localStorage 키가 `theme` 이 아니라 **`sms_theme`** | 심은 뒤 `data-theme` 로 **확인** |
| 12 | 「스크립트가 성공했다」 | **이어 붙인 명령은 앞이 실패해도 뒤가 돈다** | 커밋 전에 **의도한 변경이 들어갔는지** 세어 본다 |

**공통 규칙 셋**
1. **파이프를 걷고 원시 출력을 한 번 봐라.** 특히 «막 고친» 도구의 «첫 숫자».
2. **판정 축과 결론 축이 같은지 봐라.** 「이 축에서 0건」은 「결함 0」이 아니다.
3. **오류를 삼키는 catch 를 만들지 마라.** 삼키면 그 위 모든 판정이 거짓말이 된다.

## 5. 보안·세션 시나리오 (로그인 쪽을 고쳤으면 반드시)

```
여러 앱 동시 로그인      goditor·godiv·web 이 서로 «안 밀어내나»
같은 앱 두 기기          MAX_PER_APP=2 → 둘 다 살아있나 · 세 번째는 가장 오래된 것만 밀리나
비밀번호 «변경»          전 기기 로그아웃 되나 (sessions[] 와 sessionToken «둘 다»)
비밀번호 «재설정»        같음
새 비번 로그인 / 옛 비번  되나 / 차단되나
틀린 토큰                거부되나 (기록이 «안» 갱신되는 것으로 확인)
```
★세션 모델이 **둘**이다(`sessions[]` 배열 · `sessionToken` 한 칸). **새 코드는 둘 다 봐야 한다.**
한 곳만 고치면 어긋난다 — `download.js` 가 실제로 그렇게 깨져 있었다.

## 6. 파일을 「갈랐을」 때 (CSS/JS 분리)

⛔**선택자 자동 측정을 믿지 마라.** 가상클래스를 벗기다 선택자가 망가진다
(`.kko` 를 「3장이 쓴다」고 했는데 실제로는 1장이었다).

**판정은 두 가지로만:**
1. **마크업·JS grep** — 그 클래스가 실제로 어디 있나
2. ★**분리 전후 「계산 스타일 대조」** — 영향받는 **모든 페이지**를 재서 **차이 0건**

★2026-09-03 에 `home.css` 분리가 이 대조에서 걸렸다(`opacity 1→0`). **8장만 보고 배포했다가
되돌렸다** — 다음엔 **18장 전부 대조한 뒤** 배포한다.

**선언 보존 검사**도 같이: 분리 전 CSS 선언 집합 ⊆ 분리 후 합집합. 잃은 선언 0건.

## 7. 배포 후 «반드시»

```
1. CSS/JS 를 고쳤으면 ?v= 를 «같이» 올린다   ← 안 올리면 옛 파일이 나간다(실제로 두 번 당함)
   ★현재 버전을 파일에서 «읽어» 올린다. 고정 문자열 치환 금지(패턴이 안 맞으면 조용히 넘어간다)
2. git push  →  EC2 수동 배포  →  Cloudflare purge
3. 라이브에서 «실제로» 확인한다 (curl 로 그 문자열이 나오는지)
4. api/ 파일은 docroot 가 아니라 «원래 경로»로 — 그리고 systemctl restart
```
⛔`/tmp` 통째 cp 금지 · `git add -A` 금지 · docroot 안에 백업 금지
