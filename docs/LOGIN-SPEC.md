외에 어떤 기능이 빠졌는지 스터디하고 규격화 해놔」)

이 문서는 **「로그인하면 무엇이 달라져야 하는가」의 정본**이다.
새 페이지를 만들 때 이 목록을 훑고, 빠진 칸이 있으면 여기부터 고친다.

> ⛔**「없다」와 「안 만들었다」를 구분해 적었다.** 아래 ⛔ 항목은 실제로 코드가 없다는 뜻이고,
> 「⚠️부분」은 일부 경로에서만 동작한다는 뜻이다. 추측으로 채우지 않았다 — 전부 코드에서 확인했다.

## B. 빠진 것 — 우선순위 순

| # | 항목 | 왜 필요한가 | 크기 |
|---|---|---|---|
| **B1** | **로그인 유지** | ⛔지금 세션은 `sessionStorage` 라 **탭을 닫으면 로그아웃**된다. 일반 사이트의 기본값(「로그인 상태 유지」 체크박스 + 장기 토큰)이 없다. 사용자는 «자꾸 풀린다»고 느낀다 | 중 |
| **B2** | **회원 탈퇴** | ⛔코드가 **아예 없다**. 개인정보보호법상 이용자는 언제든 동의를 철회하고 파기를 요구할 수 있어야 한다. 지금은 메일로 부탁하는 길뿐 | 중 |
| **B3** | **마케팅 수신 동의 변경** | ⛔가입 때 받고 **바꿀 수 없다**. 철회 수단이 없으면 동의 자체가 흠결이 된다 | 소 |
| **B4** | **로그인 실패 횟수 제한** | ⛔`login.js` 에 제한이 **없다**. 비밀번호 찾기엔 있는데(시간당 3회) 정작 로그인이 무제한이라 대입 공격에 열려 있다 | 소 |
| **B5** | **되돌아오기(next)를 전 페이지로** | ⚠️부분. `next` 를 실어 보내는 링크가 **4곳뿐**이고 나머지 34곳은 맨 `login.html` 이다. 보호된 자리에서 튕긴 사람이 원래 보던 곳으로 못 돌아온다 | 소 |
| **B6** | **다른 기기에서 로그아웃** | ⛔비밀번호를 바꿔야만 전 기기가 풀린다. 「지금 로그인된 기기 목록」과 개별 해제가 없다 | 중 |
| **B7** | **최근 로그인 기록 / 새 기기 알림** | ⛔없다. 계정 도용을 본인이 알아챌 방법이 없다 | 중 |
| **B8** | **이메일 인증** | ⚠️`EVENT_MODE` 로 **생략 중**. 베타가 끝나면 켜야 하고, 그 순간 미인증 계정 처리 규칙이 필요하다 | 중 |
| **B9** | **소셜 로그인 / 2단계 인증** | ⛔없다. 지금 규모에선 급하지 않다 | 대 |
| **B10** | **내 데이터 내려받기** | ⛔없다. 법적 필수는 아니나 요구가 오면 손으로 뽑아야 한다 | 소 |

## C. 규칙 (새 화면을 만들 때 지킬 것)

1. **상단바는 `nav-auth.js` «하나»가 맡는다.** 페이지마다 상단바를 손대면 한쪽만 고쳐진다
   (실제로 `mypage.js` 가 따로 손대다가 «자기 자신을 가리키는 링크 + 로그아웃 없음»이 됐다).
2. **로그인 상태는 표시만, 판정은 서버가.** `nav-auth.js` 는 토큰 «존재»만 보고 화면을 바꾼다.
   권한 판정은 API 에서 한다 — 상단바 한 줄 때문에 전 페이지가 세션 API 를 때리지 않는다.
3. **등급은 «계정»에 붙는다.** 앱마다 따로가 아니다. 화면에 등급을 그릴 땐 «적용 범위»를 같이 적는다
   (안 적었더니 「이용 중인 서비스가 없는데 무슨 베타냐」가 나왔다).
4. **로그인은 목적지가 아니라 수단이다.** 로그인 화면에 머물게 하지 않는다.
5. **없는 기록을 지어내지 않는다.** 사용 기록이 없는 앱은 「기록 없음」으로 그린다. 0회·오늘 날짜로 채우지 않는다.
6. **로그아웃할 문이 없는 화면을 만들지 않는다.** 공용 PC 를 전제한다.
7. **CSS/JS 를 고치면 `?v=` 를 «같이» 올린다.** 안 올리면 라이브 파일은 새것인데 화면만 옛것이라
   「코드가 틀렸다」고 오진한다(2026-09-03 실제 발생).

## D. 현재 세션 구조 (사실)

- 브라우저: `sessionStorage.sms_token` / `sms_email` / `sms_plan` / `sms_until` / `sms_orders`
- 서버: `users.sessions = [{ app, token, issuedAt }]` — **앱당 1개**(`MAX_PER_APP = 1`, 계정 공유 억제용 정책값)
- **서버 토큰에 만료가 없다.** 새 로그인이 같은 앱 칸을 덮어쓸 때만 사라진다.
  ⇒ B1(로그인 유지)을 붙일 때 «서버 만료»도 같이 정해야 한다. 지금 브라우저가 탭 종료로
    끊어 주는 덕분에 가려져 있는 문제다.
